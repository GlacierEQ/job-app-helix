# Quality-Forward Development

The Helix tree grows cumulatively. `main` remains the canonical system; branches are growth and source material. A branch is inspected against the tree, its beneficial elements are selectively transcribed, defects are repaired in context, and lineage is preserved.

## Default question

> What is the strongest coherent improvement that can become true next?

Scope is controlled by authority, real risk, reversibility, dependencies, and evidence—not by a preference for less work.

## Quality levels

1. **Working** — the intended behavior runs on the real path.
2. **Sound** — relevant tests, contracts, failure handling, evidence, and regression checks exist.
3. **Release-quality** — integration, provenance, documentation, recovery, and changed-surface gates are healthy.
4. **Elite** — concise, humanized, maintainable, compositional, observable, resource-aware, and powerful in actual use.

A check blocks only when it directly tests the changed behavior, safety boundary, public or sensitive exposure, dependency integrity, or rollback path. Advisory and unrelated checks become tracked follow-up work; they do not freeze a workable improvement.

## Engineering standard

Build 9+ professional code: short, explicit, testable, runnable, observable, recoverable, and human-readable. Remove accidental complexity without reducing capability. The agent owns routine inspection, diagnosis, implementation, testing, evidence collection, and integration so the operator is not the bottleneck.
