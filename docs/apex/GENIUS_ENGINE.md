## Loop (v3)

```text
RESEARCH / STUDY (mandatory)
  → invent candidates (signal-biased mechanism library)
  → attack (theater / paralysis / shallow)
  → rank
  → advance brief (paths, tests, refuse steps)
  → accumulate lite knowledge (machine/genius_knowledge/)
  → publish library-of-links entry (if checkout/env present)
```

### Research

Every run studies the leaf before inventing:

- subject fields + optional live GitHub surface (`gh api`)
- signals (telemetry, mcp, neutralization, hollow, …)
- lite facts accumulated across runs
- prior primary mechanism (soft diversity)

Offline: `--offline` or `GENIUS_OFFLINE=1`.

### Knowledge + Library of Links

| Store | Path |
|---|---|
| Helix lite knowledge | `machine/genius_knowledge/{repo}.json` + `index.json` |
| Library of Links | `GENIUS_LIBRARY_OF_LINKS_ROOT` or `~/.grok/work/library-of-links` → `domains/genius/`, `registry/index.json` |

Repo: [GlacierEQ/library-of-links](https://github.com/GlacierEQ/library-of-links)

## Commands

```bash

  --repository GlacierEQ/spacex-telemetry \
  --paper-recovery --neutralization-stamps 2 \
  --markdown

# Offline / CI-friendly
PYTHONPATH=src python scripts/genius_engine.py invent \
  --repository GlacierEQ/megamind --offline --markdown

# Restoration
PYTHONPATH=src python scripts/genius_engine.py restore \
  --repository GlacierEQ/glaciereq-mcp-stack

  --repository GlacierEQ/xai-colossus-cooling --offline

```

## What improved in v3

| v2 weakness | v3 fix |
|---|---|
| Template implementation | Leaf-native module/test/receipt paths per repo + language |
| Mechanism clustering | Signal-biased selection; anti-neut only when justified |
| Score self-bonus | Novelty scores problem/cause/mechanism — not craft adjectives |
| No research | Mandatory research/study phase |
| No memory | Lite knowledge accumulation |
| No link library | Publishes to library-of-links |
| Invent only | Advance brief with concrete steps/paths |

## Scoring (honest rank, not freeze)

- **novelty** — mechanism specificity + leaf name in problem + research density  
- **coherence** — complete fields, leaf paths, refuse tests, dual-plane receipts  
- **genius** — weighted composite  
- Attack rejects theater, paralysis, shallowness — **not** ambition
