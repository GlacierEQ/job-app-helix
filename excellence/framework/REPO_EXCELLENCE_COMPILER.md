## Gatling / tsunami / unified memory

- **Gatling:** many leaves in parallel at the same stage  
- **Tsunami:** every gate PASS writes a receipt into memory bus / jsonl  
- **Unified memory:** next worker reads estate donors + prior proof, not a blank mind  

Orchestrator stays lean; leaves run make-it-heavy.
