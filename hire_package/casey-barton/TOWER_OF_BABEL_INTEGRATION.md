# Tower of Babel Integration

The Casey Barton recruiter package composes Job-App Helix with the Tower of Babel as a **scoped technology-placement, interoperability, and proof capability**.

## Why the Tower belongs here

Job-App Helix coordinates candidate evidence, portfolio intelligence, application state, restoration, and recruiter projection. Tower contributes a different capability: **which technology best fits a responsibility, when it should activate, how it interoperates, and what proof should demonstrate that boundary**.

The systems compose without creating project-direction hierarchy:

```text
candidate objective / target role
              │
              ▼
      Job-App Helix
portfolio intelligence · evidence · application state
              │
              ▼
      Tower of Babel
technology placement · interfaces · proof gates · blockers
              │
              ▼
 recruiter / engineer / AI presentation
              │
              ▼
 deterministic package and repository receipts
```

Casey Barton retains project-direction authority. Repository-native source remains authoritative for factual implementation state. Tower recommendations and proof gates are scoped engineering inputs, not authority over the estate or the Operator.

## Recruiter signal

Tower demonstrates that polyglot engineering can be treated as evidence-backed technology placement rather than language collection. A technology earns its place through a measurable boundary such as native safety, browser reach, statistical rigor, database correctness, hardware acceleration, formal proof, interoperability, latency, reliability, or developer ergonomics.

## Evidence rules

- `verified`, `tested`, `integrated`, and `formally_verified` remain stronger evidence states than `illustrative`.
- `hardware_gated`, `toolchain_gated`, and `service_gated` remain explicit blockers.
- Repository source is not silently promoted into deployment proof.
- New technologies should displace working components only when the new design creates a stronger evidenced result at the relevant boundary.
- Machine ingestion must preserve the same claim and blocker states shown to humans.
- Technology-placement recommendations never become project-direction authority by being recorded in Tower.
