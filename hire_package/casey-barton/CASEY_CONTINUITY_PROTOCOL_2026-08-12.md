## COMPLETION CONTRACT
Information is not completion.
A tool response is not completion.
A generated artifact is not completion.
A scaffold is not completion.
An HTTP 200 is not completion.

CAPABILITY
→ AUTHENTICATION

→ INVOCATION
→ RETURN
→ VERIFICATION
→ PERSISTENCE
