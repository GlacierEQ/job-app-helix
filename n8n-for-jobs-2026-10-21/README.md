# n8n for Jobs — evidence bundle

Gathered 2026-10-21 at the Operator's direction ("Let's gather the n8n data for jobs").
Purpose: one place a pack builder or the Operator can pull n8n claims from, with every
number carrying its receipt and its date — and the honesty boundaries attached, so no
application ever claims more than the record holds.

## Contents
- `01_INVENTORY.md` — the enumerated estate: exports in hand (5), the 9-workflow
  self-hosted enumeration (2026-10-20), the executed failure-lab suites (2026-10-15),
  credentials (types only), usage volume, security audit.
- `02_PROOF_SHEET.md` — the career-proofs-convention proof (Claim / Evidence /
  Verified), resume bullets mapped to receipts, honesty boundaries, limitations.
  Supersedes the 2026-10-17 `n8n-estate.md` proof in GlacierEQ/job-application.
- `03_TALKING_POINTS.md` — interview/application answers built from the workflow
  code itself, plus the tripwires (what not to claim).
- `LIVE_PROBE_2026-10-21.md` — today's fresh readback attempt, both routes, exact
  results. Read this before citing any count as current.
- `exports/` — 5 workflow JSONs + the Master Agent prompt v1. Byte-identical copies
  of the originals (hashes cross-checked at build time).
- `SHA256SUMS.txt` — SHA-256 for everything in `exports/`.

## The gap this closes
As of 2026-10-21, no PROOFS.md in the Oct 20–21 submission waves mentions n8n — the
strongest automation evidence in the estate was attached to exactly one email
(Massive, Oct 20) and cited nowhere else. Cite `02_PROOF_SHEET.md` when a role is
automation-, FDE-, or AI-platform-shaped.

## Rules for use
1. Numbers travel with their dates. "9 active workflows (2026-10-20 readback)."
2. The honesty boundaries in the proof sheet are part of the proof. Quote them
   when a JD tempts a bigger claim.
3. Exports are clean to attach (scanned 2026-10-21: no credentials, keys, or
   pinned data). Re-scan after any re-export.
4. Refresh the live pull when the Cloud data plane answers again; update the
   Verified date, never a number without a readback behind it.
